# Landing Page Themes

The super admin's **Appearance → Themes** screen builds the platform's own public landing page — the page a prospective merchant sees before they register — from a stack of sections, with a live preview beside it. These are the platform-facing themes, separate from the [storefront themes](/tenants/storefront-themes) a tenant applies to their store.

::: info What you'll learn
- What the landing page sections are
- How to add, reorder, and edit sections with the live preview
- How drafts and publishing work
:::

## The section editor

Go to **Appearance → Themes**. The left panel lists the **Sections** that make up the landing page, top to bottom; the right side shows a live **Preview** of the page. Switch the preview between **Desktop**, **Tablet**, and **Mobile** to check each layout, and use the **Locale** switcher to edit the landing page in another language when more than one is enabled.

<ImagePopup src="/images/themes/settings-themes.png" alt="Landing page section editor" />

- Select **Create Section**, enter a **Name**, choose a **Type**, and select **Save Section**.
- Drag a section up or down to change where it appears.
- Use a section's toggle to make it **Active** or **Inactive**.
- **Duplicate** a section to start from a copy, or **Delete** it.
- Select a section to edit its content — headings, text, buttons, images, and the other fields its type offers.

## Section types

- **Hero Signboard** — the headline block at the top of the page: a heading, lede, and a store-name box where a visitor can claim their store address and start registering.
- **Slider Carousel** — a rotating banner of images.
- **Platform Counters** — headline figures about the platform, each with a label, value, and optional prefix or suffix.
- **Feature Ledger** — a list of what every plan includes, each item with an icon, title, and description.
- **House Split** — a side-by-side picture of a store's front (the storefront, with sample products) and back (the admin panel, with sample KPIs and orders).
- **Opening Steps** — numbered steps explaining how to open a store.
- **Shop Talk** — merchant quotes, each with an attribution.
- **Pricing** — your subscription plans, with a monthly/yearly toggle and an optional highlighted plan.
- **CTA Signoff** — a closing call to action.
- **Static Content** — free-form content.
- **Footer Links** and **Services Content** — the page footer. Each can appear only once and is pinned to the bottom of the page.

## Drafts and publishing

Changes in the editor are held as a **draft**. New sections, edits, toggles, and reordering all wait until you are ready, and the header counts them as **Unsaved changes**. A new section starts inactive.

- Select **Publish** to put every pending change live on the landing page at once.
- Select **Discard** to throw the draft away and return to the published page.

::: tip
This is where you shape the first impression a prospective merchant gets. Keep the hero and pricing sections accurate — they are what convinces a visitor to open a store. Preview on **Mobile** before publishing; many visitors arrive on a phone.
:::

The landing page's own logo, favicon, SEO tags, languages, and maintenance mode are set separately under [Configuration → General → Design](/content/configuration#general).
